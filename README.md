# Discord Welcome Bot

Бот для автоматического приветствия новых участников Discord сервера.

## Функции
- Автоматически выдает роль новым участникам
- Отправляет приветственное сообщение в указанный канал

## Установка

1. Установите зависимости:
```bash
npm install
```

2. Создайте файл `.env` на основе `.env.example`:
```bash
cp .env.example .env
```

3. Заполните `.env` файл:
   - `DISCORD_TOKEN` - токен вашего бота (получите на https://discord.com/developers/applications)
   - `WELCOME_CHANNEL_ID` - ID канала для приветствий (ПКМ на канал → Копировать ID)
   - `WELCOME_ROLE_ID` - ID роли для новых участников (Настройки сервера → Роли → ПКМ на роль → Копировать ID)

## Настройка бота в Discord Developer Portal

1. Перейдите на https://discord.com/developers/applications
2. Создайте новое приложение
3. Перейдите в раздел "Bot" и создайте бота
4. Включите следующие Privileged Gateway Intents:
   - SERVER MEMBERS INTENT (обязательно!)
5. Скопируйте токен бота
6. Перейдите в раздел "OAuth2" → "URL Generator"
7. Выберите scope: `bot`
8. Выберите permissions: `Manage Roles`, `Send Messages`
9. Скопируйте сгенерированную ссылку и добавьте бота на сервер

## Запуск

```bash
npm start
```

## Важно
- Роль бота должна быть выше роли, которую он выдает новым участникам
- Включите "Режим разработчика" в Discord (Настройки → Расширенные) для копирования ID
